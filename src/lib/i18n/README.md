# Локализация Freedom Platform

Интерфейс использует `i18next` и поддерживает `az`, `ru` и `en`.

Все три языка покрывают весь интерфейс. Если ключа нет в выбранном языке, используется русский
fallback-каталог, но сборка не пропустит ключ без английского или азербайджанского перевода.

## Где исправлять перевод

- Основной русский каталог: `locales/ru.json`
- Основной азербайджанский каталог: `locales/az.json`
- Основной английский каталог: `locales/en.json`
- Новые и динамические сообщения: `locales/manual.ru.json`, `locales/manual.az.json` и `locales/manual.en.json`

Значения можно редактировать вручную. Ключи менять нельзя: они используются в коде.

## Как добавить новое сообщение

1. Добавить одинаковый смысловой ключ во все три файла `manual.*.json`.
2. Использовать ключ через `const { t } = useI18n()`:

```tsx
t('orders.created')
t('orders.total', { amount })
```

3. Запустить `npm run i18n:check`.

Сборка автоматически запускает эту проверку и завершится ошибкой, если ключ отсутствует в одном из языков, перевод пустой, в английском переводе остались кириллица или другие плейсхолдеры `{{...}}` или в код добавлен динамический русский шаблон без i18n-интерполяции.
