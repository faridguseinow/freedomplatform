# Локализация Freedom Platform

Интерфейс использует `i18next` и поддерживает `ru` и `az`.

## Где исправлять перевод

- Основной русский каталог: `locales/ru.json`
- Основной азербайджанский каталог: `locales/az.json`
- Новые и динамические сообщения: `locales/manual.ru.json` и `locales/manual.az.json`

Значения можно редактировать вручную. Ключи менять нельзя: они используются в коде.

## Как добавить новое сообщение

1. Добавить одинаковый смысловой ключ в оба файла `manual.*.json`.
2. Использовать ключ через `const { t } = useI18n()`:

```tsx
t('orders.created')
t('orders.total', { amount })
```

3. Запустить `npm run i18n:check`.

Сборка автоматически запускает эту проверку и завершится ошибкой, если ключ отсутствует в одном из языков, перевод пустой или в код добавлен динамический русский шаблон без i18n-интерполяции.
